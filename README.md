Hello World!
Experience the exhilarating life of a fighter pilot with this fun app!

System Requirements:
MacOS with Xcode
iOS compatible devices only (iphone/ipad)

How to compile and run:
This repository has all of the required files to create the app on your own machine. Create a new app project in Xcode and import the files and assets!

Apple Developer Mode:
Without a developer account there is no way to port the app to a real iphone, you can only use the built-in Xcode simulator.

App Features:
AI enemies
A full armament suite
Missile locking and targetting logic
A score system
Unique aircraft art that models real world jets
